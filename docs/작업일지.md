# 📒 Virtual Deck 작업일지

Virtual Deck을 다시 다듬으면서 **무엇을, 왜, 어떻게** 바꿨는지 기록합니다.
수정 전 원본은 `_backup_원본` 폴더에 그대로 보관되어 있습니다.

## 1차 작업 — 전체 개선 (2026-10-21)

### 출발점: 발견한 문제

| 구분   | 문제                                     | 원인                                                                                  |
| ------ | ---------------------------------------- | ------------------------------------------------------------------------------------- |
| 디자인 | 리퀴드 글라스 느낌이 약함                | 버튼 모양을 PNG 그림을 늘려서 만들어 흐릿하고, 유리 뒤가 비치지 않았음                |
| 디자인 | 마우스를 올리거나 눌러도 반응이 없음     | '마우스 올림' 상태를 기록만 하고 화면에 그리지 않았음                                 |
| 디자인 | 설정창이 메인 창과 따로 노는 느낌        | 설정창은 회색 배경의 기본 모양이었음                                                  |
| 버그   | 메모장 아이콘이 깨져 있음                | 아이콘 위치를 `C:\ShinJaeWan\...` 같은 고정 경로로 저장했는데 폴더가 옮겨짐         |
| 버그   | EXE로 만들면 디자인·설정이 사라짐       | 빌드 스크립트에 그림·아이콘 폴더가 빠져 있었고, 저장 위치가 '실행한 위치' 기준이었음 |
| 버그   | 단색/그라데이션 배경이 작동 안 함        | 설정 값만 있고 고르는 화면도, 그리는 코드도 없었음                                    |
| 버그   | 칸을 줄였다 늘리면 지운 버튼이 다시 나옴 | 밖으로 밀려난 버튼 정보가 계속 남아 있었음                                            |
| 버그   | 매크로 글자 입력 중 튕길 수 있음         | 작업 줄(스레드)에서 화면 쪽 클립보드를 건드렸음                                       |
| 사용감 | 단축키가 가끔 엉뚱한 곳으로 감           | 덱을 누르면 덱이 포커스를 가져갔다가 돌려주는 방식이었음                              |

### 한 일

**① 유리 디자인을 코드로 직접 그리기** — `ui/glass.py` (새 파일)

- 유리 한 장을 7겹으로 그립니다: 그림자 → 몸통(뒤 배경 살짝 확대) → 아래쪽 안쪽 빛 → 테두리 두께 띠 → 위쪽 반사광 → 밝은 윗면/어두운 아랫면 테두리 → 모서리 무지개빛
- 그림 파일을 쓰지 않아 어떤 크기에서도 선명하고, 색을 마음대로 바꿀 수 있습니다.
- 버튼 아이콘(설정, 닫기 등)도 선으로 직접 그려서 늘 선명합니다.

**② 색을 한곳에서 관리** — `ui/theme.py`

- 밝은/어두운 테마 색, 유리 색 8가지(투명·주황·파랑·민트·보라·분홍·빨강·노랑)를 이 파일에 모았습니다.
- Pretendard 글꼴을 프로젝트에 넣어 어느 컴퓨터에서나 같은 모습으로 보이게 했습니다.

**③ 공용 유리 부품** — `ui/widgets.py` (새 파일)

- 유리 버튼, 켜기/끄기 스위치, 알약 모양 탭, 색 고르기 칩, 유리 대화상자, 단축키 입력칸, 확인 창
- 모든 창이 이 부품을 같이 써서 모양이 통일됩니다.

**④ 덱 뒤가 비치는 배경** — `ui/backdrop.py` (새 파일)

- 덱 뒤 화면을 찍어서 흐리게 만든 뒤 배경으로 씁니다.
- 덱 창이 그 사진에 같이 찍히지 않도록 Windows의 '캡처에서 빼기' 기능을 켭니다.
  (그래서 이 배경을 쓰는 동안에는 화면 캡처나 화면 공유에 덱이 보이지 않습니다)
- 화면이 바뀌지 않았으면 다시 그리지 않아 컴퓨터에 부담을 덜 줍니다.
- 단색 / 그라데이션 / 이미지 배경도 실제로 작동하게 했습니다.

**⑤ 포커스를 빼앗지 않는 덱** — `core/win32.py`, `ui/main_window.py`

- 덱을 눌러도 지금 쓰는 프로그램이 계속 앞에 있도록 Windows 창 설정을 바꿨습니다. 실제 스트림덱처럼 동작합니다.

**⑥ 키 입력 방식 교체** — `core/win32.py`, `core/shortcut_manager.py`

- 오래된 방식(keybd_event) 대신 최신 방식(SendInput)으로 키를 보냅니다.
- 방향키, Home/End, F13~F24, 기호 키, 볼륨·미디어 키를 추가했습니다.
- 매크로 글자 입력은 클립보드 없이 글자를 직접 보내서, 복사해 둔 내용이 지워지지 않고 튕기지도 않습니다.

**⑦ 매크로 개선** — `core/macro_manager.py`, `ui/macro_editor_dialog.py`

- 실행 중에는 버튼에 도는 고리가 보이고, 다시 누르면 멈춥니다.
- 단계를 두 번 클릭해서 고치기, 복제하기를 넣었습니다.

**⑧ 새 기능**

- 우클릭 메뉴: 편집 · 복사 · 붙여넣기 · 비우기 · 되돌리기
- 버튼 묶음(폴더 버튼), 켜기/끄기 버튼, 볼륨·미디어 버튼
- `Ctrl + Alt + D`로 덱 숨기기/보이기 (`core/system_integration.py`)
- 컴퓨터를 켤 때 자동 실행
- 화면 가장자리에 자석처럼 붙기, 안 쓸 때 흐려지기
- 실행에 실패하면 덱 아래에 작은 알림 (`ui/toast.py`)
- 아이콘 자동 가져오기: 프로그램/파일 아이콘, 웹사이트 아이콘 (`core/icon_fetcher.py`)
- 프로필 내보내기/가져오기 (아이콘 그림까지 파일 하나에)
- 설정창을 배치 / 모양 / 배경 / 동작 탭으로 정리, 바꾸는 즉시 덱에 미리 보임

**⑨ 안정성**

- 저장 위치를 '프로그램이 있는 폴더의 data'로 고정 (`core/paths.py`)
- 아이콘은 `icons/xxx.png` 같은 상대 경로로 저장하고, 예전 고정 경로는 파일 이름으로 다시 찾아 자동 복구
- 저장할 때 임시 파일에 먼저 쓰고 바꿔치기 → 저장 중 꺼져도 파일이 깨지지 않음, 직전 파일은 `config.json.bak`
- 칸을 줄이면 지워질 버튼 수를 먼저 알려 주고 확인
- 프로그램이 두 번 켜지지 않도록 막음
- EXE 빌드에 글꼴·아이콘을 포함하고, 유리 앱 아이콘을 코드로 만들어 사용

### 확인한 것

- 작업 공간(리눅스)에서 화면 없이 실행해 모든 창을 캡처해서 모양을 확인
- 37가지 동작 테스트 통과 (버튼 바꾸기, 되돌리기, 묶음, 칸 줄이기, 내보내기/가져오기, 매크로 멈추기, 설정 미리보기 등)
- 사용자의 기존 `config.json`으로 실행해서 깨진 메모장 아이콘이 복구되는 것 확인
- ⚠️ Windows 전용 기능(실제 키 보내기, 전역 단축키, 뒤 비침, 자동 실행)은 작업 공간이 Windows가 아니라서 실행해 보지 못함 → 사용자 컴퓨터에서 확인 필요

## 2차 작업 — 간격 · 투명도 · 애니메이션 · 아이콘 테마 (2026-10-21)

### 받은 의견

> 버튼 간격이 너무 떨어져 있다. 배경이 불투명해서 유리 느낌이 약하다 (색감은 그대로).
> 클릭 애니메이션을 넣고, 아이콘 테마로 통일감을 주면서 직접 꾸미는 느낌도 강화하자.

### ① 버튼 간격 줄이기

- **원인:** 버튼마다 그림자가 들어갈 자리로 둘레에 큰 여백(버튼 크기의 8.5%)을 비워 두었습니다. 그래서 간격을 6으로 해도 실제로는 20px 넘게 떨어져 보였습니다.
- **해결:** 그림자와 바깥 빛을 버튼이 아니라 **버튼판(덱 본체)이 한꺼번에 그리도록** 바꿨습니다. 그래서 버튼 여백을 4.5%로 줄여도 그림자가 잘리지 않습니다.
  - `ui/glass.py`: 그림자 부분을 `paint_glass_under()`로 따로 분리
  - `ui/main_window.py`: 덱 본체(`DeckPanel`)가 모든 버튼의 그림자를 먼저 그림
  - `ui/deck_button.py`: 버튼은 유리 몸통만 그리고, 다시 그릴 때 버튼판에도 알려 줌
- 간격 기본값도 줄였습니다 (보통 크기 10 → 6).
- **기존 설정 자동 변환:** 예전 설정 파일이면 간격을 60%로 줄여 줍니다 (사용자 설정 6 → 4). 한 번만 바뀌도록 `layout_version` 값으로 표시합니다. (`models/config_model.py`)

### ② 더 투명한 유리

- 배경 위에 덮던 흰 막의 진하기: 92 → **약 50** (255가 완전 불투명, 밝은 테마 기준)
- 흐림 정도 기본값: 22 → **14** (예전 기본값이었다면 자동으로 바꿈)
- 버튼 속 흰 채움: 22% → **11%**
- 렌즈 효과(뒤가 살짝 확대돼 보이는 것): 9% → **14%**, 누르면 더 커짐
- 덱 본체 위쪽 반사광도 조금 약하게
- **새 설정:** 설정 → 배경 → 유리 → **"유리 뿌옇기"** 슬라이더 (0 = 아주 맑음, 100 = 젖빛 유리)
- 투명해져도 글자·아이콘이 잘 보이도록 둘레에 은은한 빛(흰색/검은색)을 둘렀습니다.
- 색감(유리 색 8가지)은 바꾸지 않았습니다.

### ③ 클릭 애니메이션

| 대상                 | 효과                                           | 어떻게                                                       |
| -------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 덱 버튼 · 유리 버튼 | 누르면 쏙, 놓으면 통 튀어 오름                 | 놓을 때 '살짝 지나쳤다 돌아오는' 움직임(OutBack) 사용        |
| 덱 버튼 · 유리 버튼 | 누른 자리에서 물결                             | 누른 위치에서 커지는 둥근 빛 고리                            |
| 켜기/끄기 덱 버튼    | 켜질 때 색이 누른 자리에서 번짐                | 이전 상태 위에 원 모양으로 새 상태 유리를 점점 크게 그림     |
| 스위치               | 손잡이가 물방울처럼 늘어남, 민트가 따라 차오름 | 움직이는 중간에 손잡이 폭을 넓힘, 누르고 있으면 조금 더 넓게 |
| 탭                   | 알약이 액체처럼 늘어났다 따라붙음              | 가는 쪽 끝은 빨리, 반대쪽 끝은 늦게 움직임                   |
| 색 칩                | 고르면 톡 튀어나옴                             | 작아졌다 커지는 반동                                         |

- 함께 정한 규칙: **켜기/끄기 버튼은 꺼지면 투명 유리, 켜지면 고른 색(기본 민트)** — 참고 이미지의 스위치와 같은 방식이고, 켜짐/꺼짐이 한눈에 보입니다.
- 고친 문제: 유리를 그릴 때 바깥 테두리 모양 제한을 '덮어쓰기'로 처리해서 색 번짐이 한 번에 꽉 차 보였음 → '겹치는 부분만'으로 바꿔서 해결

### ④ 아이콘 테마 + 꾸미기

- **기본 아이콘 76개를 코드로 그림** — `ui/icons.py` (새 파일)
  - 같은 선 굵기, 둥근 끝, 같은 크기 기준이라 덱 전체가 통일돼 보입니다.
  - 분류: 자주 쓰는 / 편집 / 미디어 / 브라우저·화살표 / 작업·생활
  - 버튼에는 `icon:volume_up` 같은 이름으로 저장됩니다.
- **아이콘 스타일 3가지** (설정 → 모양): 선 / 두 톤(선 + 옅은 색 채움) / 이모지(같은 뜻 이모지로 표시)
- **버튼마다 아이콘 색**: 자동 / 흰색 / 진한 색 / 하늘 / 민트 / 주황 / 분홍 / 노랑 / 보라 (`icon_color` 항목 추가)
- **아이콘 고르는 칸 새로 구성** (버튼 편집창): [테마 아이콘 | 이모지 | 그림 파일] 탭
  - 이모지 탭: 추천 이모지 + 직접 입력
  - 그림 파일 탭: 그림 고르기, 프로그램·파일 아이콘 가져오기, 사이트 아이콘 가져오기
- **자동 아이콘**: 아이콘을 직접 고르지 않았다면, 동작을 바꿀 때 아이콘도 맞춰 바뀝니다 (예: 볼륨 + → 스피커 아이콘). 직접 고른 아이콘은 그대로 유지됩니다.
- 처음 설치 때 들어가는 기본 버튼도 모두 테마 아이콘으로 바꿨습니다.
- **기존 버튼 변환**: 설정 → 모양 → "이모지 아이콘을 테마 아이콘으로 바꾸기" (모든 프로필 한 번에, 덱 우클릭 → 되돌리기로 전체 되돌리기 가능)
- 되돌리기가 '모든 프로필'을 한 번에 되돌릴 수 있도록 확장했습니다. (아이콘 일괄 변환, 칸 줄이기에 사용)

### 확인한 것

- 화려한 색의 가짜 바탕화면 위에 덱을 띄워 투명도를 확인 (뒤의 글자 창과 초록 원이 비쳐 보임)

### ① pycaw 자동 확인 · 설치

- **알아 둘 점:** EXE 안에는 파이썬과 pip 가 들어 있지 않아서, **EXE 가 실행 중에 pycaw 를 설치할 수는 없습니다.**
  그래서 두 갈래로 나눠 처리했습니다.

| 실행 방법                     | 동작                                                                                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| EXE 만들기 (`build_exe.py`) | pycaw 가 없으면 **자동으로 설치**한 뒤 EXE 안에 함께 넣음 → 만들어진 EXE 는 따로 설치할 것이 없음                                                                 |
| `python main.py`            | 시작 1.5초 뒤 pycaw 확인 → 없으면 "설치할까요?" → **설치하기**를 누르면 화면이 멈추지 않게 백그라운드에서 설치하고, 끝나면 알림. 다시 켜지 않아도 바로 사용 가능 |
| "나중에"를 고른 경우          | 다음부터는 묻지 않음. 설정 → 동작 → **pycaw 지금 설치하기** 버튼으로 언제든 설치                                                                                 |
| pycaw 없이 만든 EXE           | "이 EXE 에는 pycaw 가 빠져 있어요. build_exe.py 로 다시 만들면 들어가요" 안내                                                                                            |

- 파일: `core/dependencies.py`(새 파일), `build_exe.py`, `ui/main_window.py`(_check_pycaw), `ui/settings_dialog.py`

### ② 타이머 · 스톱워치 버튼

- 새 동작 종류 **'타이머 · 스톱워치'** (버튼 편집 → 누르면 할 일)
  - **카운트다운:** 1분·3분·5분·10분·25분·1시간 빠른 선택 + 분/초 직접 입력
  - **스톱워치:** 0부터 올라감
- **사용법:** 누르면 시작 → 다시 누르면 일시정지 → 다시 누르면 이어서. **길게 누르면 처음으로** (우클릭 메뉴 "타이머 처음으로"도 가능)
- **화면:** 남은 시간을 크게 표시하고, 테두리 고리가 남은 시간만큼 줄어듦. 일시정지면 흐려지고 ‖ 표시

- **덱을 숨겨도, 프로필을 바꿔도 계속 흘러감** — 타이머 상태를 버튼마다 따로 기억하고, 덱이 숨겨져 있어도 시간 확인은 계속함

# 6차 작업: 반응 속도 개선, 여백 축소, 위쪽 메뉴 알약 분리, 모달리스 창 전환, 환경설정 전면 개편, 일상 용어 정비

## 1. 사용자 의견 및 개선 배경

1. **반응 속도**: 버튼판을 화면에서 끌 때 버벅거림이 느껴지고, 스타일이나 설정을 바꿀 때 멈칫거림.
2. **외형 및 여백**: 버튼판 바깥 여백이 너무 넓고, 상단 메뉴가 항상 자리를 차지하여 좁은 화면에서 부담스러움.
3. **창 조작의 불편함**: 환경설정과 버튼 설정 창이 모달(Modal)이라 창이 열린 동안 버튼판을 조작할 수 없고 한가운데를 가림.
4. **설정 흐름 및 용어**: 설정 창의 탭이 복잡하고 글씨가 작으며, '덱', '매크로' 등 생소한 개발 용어가 많음.
